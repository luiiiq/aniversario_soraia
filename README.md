# Save The Date – Soraia

Projeto desenvolvido para apresentar o **Save the Date da comemoração dos 50 anos da Soraia**.

A página foi criada com uma proposta visual nostálgica, trazendo fotografias, animações, vídeo e música para transmitir a ideia de reencontro, boas lembranças e momentos especiais.

## Funcionalidades

- **Animação de abertura:** introdução visual com o texto "Save the Date".
- **Vídeo de apresentação:** reprodução de um vídeo com frases e elementos relacionados à comemoração.
- **Transição para o conteúdo principal:** exibição das informações da festa após o término do vídeo.
- **Informações do evento:** apresentação da data e da celebração dos 50 anos.
- **Galeria de fotografias:** organização de imagens para relembrar momentos especiais.
- **Seção "Nosso Próprio Tempo":** espaço interativo para visualizar as fotografias.
- **Música de fundo:** reprodução da música após o término do vídeo de abertura.
- **Convite oficial:** indicação de que mais informações serão divulgadas em breve.

## Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd NOME_DO_REPOSITORIO
   ```

3. Abra o arquivo `index.html` no navegador.

   Recomenda-se utilizar a extensão **Live Server** no Visual Studio Code para executar o projeto localmente.
